# Identidad visual

Empresa: Xpanzia Group. Paleta: rojo, grafito, blanco y acentos dorados en el diploma.

El logo proporcionado por el usuario se conserva como archivo original en web/assets/xpanzia-logo.jpg. Se usa en navegación, cabecera móvil y diploma. El mismo archivo está incorporado como base64 en Certificate.gs, por lo que el PDF no depende de que GitHub Pages esté disponible para cargar el logo. Mantiene relación 512:138.

El fondo del diploma se adaptó con la herramienta integrada de generación de imágenes a partir de la referencia del usuario. Archivo final: web/assets/certificate-background.jpg. El texto se dibuja por separado mediante campos editables, para que nombres, curso, fecha y código no queden fijos en una imagen.
